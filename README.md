# arya-site

Personal site styled after Mass Effect (holo panels, galaxy map, Paragon/Renegade) and Persona 5 (red/black, ransom-note title, social stats, confidants, calling card).

- `npm install` then `npm run dev` to work on it locally (http://localhost:4321)
- `npm run build` makes the static site in `dist/`
- All text and links live in `src/data/profile.ts`. Empty links are hidden.
